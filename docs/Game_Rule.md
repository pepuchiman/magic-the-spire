# 概要
slay the spire のようなローグライク要素を持ったターンバトルカードゲーム。
主人公は魔法使いで各カードは魔法とする。
プレイヤーとして複数の魔法使いが存在し、それぞれパラメーターと使えるカードが異なる。
カードは自身のデッキの上から順番に手に入る。
使用したカード、捨てたカードはゴミ箱に入る（ただし、使用回数を使い切ったカードはゴミ箱に入らず破棄される）。
デッキが空になった後、さらにカードが入手できる場合、ゴミ箱のカードがシャッフルされて再度デッキが組まれ、そこから入手する。
デッキから除外する機能などを検討している為、デッキを準備するタイミングで中のカードの並び順を決定して管理する。
デッキの準備はバトル開始時に行い、所持カードをすべてシャッフルしてデッキを作る。
デッキが空の時にドローが発生した場合、ゴミ箱のカードをすべてシャッフルして新しいデッキにし、そこからドローする（デッキとゴミ箱がどちらも空の場合は、それ以上ドローしない）。

# 目的
敵を倒しながらルートを選択してダンジョンの奥に進んでいく。
マップの各階を1つずつ進み、ダンジョンの最奥（最上階）にいるボスを倒したらクリア。

# プレイヤーのパラメーター

## マナと魔法触媒の役割
- マナ：1ターンに使えるカードの「量」を決める。カードを使うと消費する
- 魔法触媒：使える魔法の「強さと色」を決める。使用条件であり、カードを使っても消費しない
- 魔法触媒はバトル中に毎ターン増えるため、序盤は弱い魔法、後半は強い魔法が使えるようになる

## パラメーター一覧
- HP：0になるとゲームオーバー
    - 0～9999の整数、初期値は20
    - 0以下になると死亡してゲームオーバーとなる（クリーチャーが残っていてもゲームオーバー）
    - 最大HPを超えない（回復は最大HPまで）
    - バトル終了後も値を引き継ぐ
- 最大HP：HPの上限
    - 1～9999の整数、初期値は20
    - 装備などの効果で増やす事ができる
- マナ：１ターンごとに使えるアクションポイント
    - 0～99の整数、初期値は0
    - 毎ターンマナ基準値にリセットされる
    - 何らかの効果によりマナ基準値を超える値になった場合でも、ターンの最初には基準値に戻る
    - カードの利用＝アクションをする為に必要（消費マナが0のカードも存在）
- マナ基準値：バトル時に毎ターンこの値にマナがリセットされる
    - 0～99の整数、初期値は5
    - カードや装備の効果で増減する事がある
- 魔法触媒(赤)：特定の魔法を使う場合に必要なパラメーター
    - 0～99の整数
    - 毎ターン触媒力(赤)の分増加する。（マナと異なり、次のターンもリセットされない）
    - 初期値はキャラクター（主人公）ごとに異なり、バトル開始時に初期値にリセットされる。
    - カードごとの必要触媒(赤)以上の値を持っている場合に、そのカードを利用できる（使用条件）
    - カードを利用しても減らない
- 触媒力(赤)：魔法触媒の増加数
    - 0～99の整数
    - 初期値は主人公ごとに異なる（主人公の個性となる）
    - この数値の分、毎ターンの開始時に魔法触媒(赤)が増加する（1ターン目は増加しない）
    - 画面上に「触媒力(赤)」のパラメーター名は表示せず、単に魔法触媒(赤)の毎ターン増加分として+1等で表現する
- 魔法触媒(青)：特定の魔法を使う場合に必要なパラメーター
    - 魔法触媒(赤)と類似。必要となるカードの種類が異なる
- 触媒力(青)：魔法触媒の増加数
    - 触媒力(赤)と類似。魔法触媒(青)の増加数を示す
- 魔法触媒(緑)：特定の魔法を使う場合に必要なパラメーター
    - 魔法触媒(赤)と類似。必要となるカードの種類が異なる
- 触媒力(緑)：魔法触媒の増加数
    - 触媒力(赤)と類似。魔法触媒(緑)の増加数を示す
- 防御力：ダメージ軽減
    - 0～9999の整数
    - 初期値は0
    - 敵からダメージを受けた場合、防御力の数値分ダメージが軽減される
- アーマー：ダメージ軽減
    - 0～9999の整数
    - 初期値は0
    - 敵からダメージを受けた場合、HPを減らす前にアーマーの数値が減り、その分のダメージが軽減される
    - アーマーで軽減しきれなかったダメージ分はHPが減る
    - アーマーはターンをまたいで残る（バトル終了時にリセット）
- 最大手札数：所持できるカードの枚数
    - 1～99の整数
    - 初期値は5
    - 手番終了時に所持カードが最大手札数を超えていた場合、最大手札数になるまでカードを捨てる
    - ドローによって最大手札数を超えてもその時点ではチェックしない（チェックは手番終了時のみ）
    - 手札はターンをまたいで残る（ターン終了時に手札をすべて捨てることはしない）
- 手札ドロー数：毎ターン増えるカードの枚数
    - 1～99の整数
    - 初期値は3
    - バトル時に、ターンの最初に手札ドロー数の数だけデッキからカードが配布される

# カードのパラメーター
- 種別：魔法の種類
    - 召喚魔法：クリーチャーを呼び出す
    - 攻撃魔法：敵にダメージを与える
    - 付与魔法：敵や味方、自分にバフやデバフを与える
    - 空間魔法：バトルの場自体に作用する
- 利用キャラクター：対象カードを利用可能なキャラクター
    - 現在のプレイヤーで利用できないカードはプレイ中に報酬として登場しない
- レアリティ：カードの強さと貴重さをあらわす
    - コモン、アンコモン、レア、レジェンドの４種類のいずれか
- ターゲット：魔法の対象
    - ターゲット種別
        - 敵：敵本体または敵のクリーチャーから1体を選ぶ
        - 自分のクリーチャー：自分のクリーチャーから1体を選ぶ（クリーチャーの種族を限定する場合あり）
        - 自分
        - 自分のクリーチャー全員
        - 自分と自分のクリーチャー全員
        - 空間
        - 敵と自分とクリーチャーのいずれか1体：敵本体、自分、敵側・自分側を問わずすべてのクリーチャーから1体を選ぶ
        - 敵と自分とクリーチャー全員：場にいる全員（敵本体、自分、敵側・自分側のすべてのクリーチャー）
    - 複数のターゲットを持つ場合もあり（ただし、1体を選ぶターゲット種別は1枚のカードに1つまで）
    - ターゲットが単体となるほとんどのカードは「敵と自分とクリーチャーのいずれか1体」とし、敵・自分・どちら側のクリーチャーでも選べるようにする
    - 「いずれか1体」「全員」で自分や自分のクリーチャーが対象になった場合も、効果はそのまま発揮される（攻撃魔法なら自分側にもダメージを与える）
- 消費マナ：カードを使う際に必要なマナ数
    - 0～99の整数
    - カードを利用すると消費マナ分、マナが減る
    - 消費マナの分のマナを持っていなければカードは利用できない
- 使用回数：1回のバトルの中で、そのカードを使える回数
    - 0～99の整数。0は「使用回数の制限なし」とする（使用回数の制限が無いカードも存在する）
    - カード1枚ごとに数える（同じカードが2枚あれば、それぞれが使用回数を持つ）
    - 使用回数を使い切ったカードは、ゴミ箱に置かれず破棄される
    - 破棄されたカードは、そのバトル中はゴミ箱にもデッキにも戻ってこない
    - 破棄はそのバトルの間だけで、次のバトルでは所持カードとしてデッキに戻り、使用回数も元に戻る
- 必要触媒(赤)：カードを使うための条件となる触媒数
    - 0～99の整数
    - 魔法触媒(赤)が必要触媒(赤)以上であれば、カードを利用できる
    - カードを利用しても魔法触媒(赤)は減らない
- 必要触媒(青)：カードを使うための条件となる触媒数
    - 必要触媒(赤)と類似
- 必要触媒(緑)：カードを使うための条件となる触媒数
    - 必要触媒(赤)と類似
- 無色カード：必要触媒(赤・青・緑)がすべて0のカード
    - 触媒の条件なしで、マナだけで利用できる
- 複数色カード：2色以上の必要触媒を持つカード
    - すべての色の条件を満たした場合に利用できる
- 効果ターン数：カードが影響を与えるターン数
    - 瞬間：カードを使った瞬間効果を発揮し、その後は何ら影響を与えない
    - 〇〇ターン：所定ターンの期間、継続して効果を発揮する
        - 効果を受けた側のターン終了時に残りターン数が1減り、0になると効果が終了する
    - バトル中：現在のバトル終了まで効果が継続する
    - 永続：バトル終了後もずっと効果が継続する（基本パラメーターの上昇など）
- 効果詳細：各カードの効果詳細
    - 様々
- 効果エフェクト：カード利用時のエフェクト
    - 様々

# クリーチャー
召喚されて場に出るキャラクターを「クリーチャー」と呼ぶ（自分側・敵側の両方。以前の呼び名は「仲間」）。
クリーチャーは基本的にカードで呼び出される。
呼び出された時点でクリーチャーのパラメーターは設定された初期値で登場する。
クリーチャーが呼び出されると自動で攻撃する。召喚したターンの「味方の攻撃」から攻撃に参加する。
クリーチャーもダメージを受け、HPが0以下になると死亡する。
自分側は、主人公＋召喚されたクリーチャー最大2体とする。
クリーチャーが2体いる状態で召喚魔法を使う場合は、入れ替えるクリーチャーをプレイヤーが指定する。入れ替えられたクリーチャーは場から消える。
クリーチャーがいる間は、敵の攻撃はクリーチャーが受ける（主人公は攻撃されない）。詳しくは「攻撃対象の決定」を参照。

# 攻撃対象の決定
- クリーチャーの攻撃・敵の攻撃（自動で行う攻撃）は、相手側のクリーチャーを先に倒さなければ、相手の本体（主人公・敵本体）を攻撃できない
- 相手側にクリーチャーが複数いる場合は、後から召喚されたクリーチャーが狙われる
- 相手側にクリーチャーがいない場合に、相手の本体（主人公・敵本体）が狙われる
- プレイヤーのカード（魔法）は、相手側にクリーチャーがいても、敵本体を含めて自由にターゲットにできる（攻撃魔法も含む）。カードのターゲット種別によっては、自分や自分のクリーチャーも選べる

# ゲームの流れ
1. タイトル画面
2. 挑戦するダンジョンを選択
3. 主人公を選択
4. マップ表示
    - マップ表示中はデッキの確認のみ可能（デッキ調整は不可。カード削除・交換は休憩ノードで行う）
5. 進路選択
6. イベントまたはバトル発生
    - ラストボスだった場合は勝利後にエンディングへ
    - クリアでゲーム要素アンロック
    - 死亡した場合はゲームオーバー画面を経てタイトル画面に戻る
7. バトル後は報酬選択
8. 4のマップ表示に戻る

# バトル中、ターンの流れ
1. 味方のバトル開始時効果発動
2. 敵のバトル開始時効果発動
3. 自分および味方のターン開始時効果発動
    - ターン開始時にマナを増やす効果は、直後のリセットで消えるため、「マナ基準値を増やす」形で設計する
4. マナが基準値に戻る
    - 魔法触媒(赤・青・緑)が、それぞれの触媒力の分増加する（1ターン目は増加しない）
5. デッキから手札ドロー数分のカードを引く
    - デッキが空になった場合は、ゴミ箱のカードをすべてシャッフルして新しいデッキにし、そこから引く
6. プレイヤーカード利用
    - マナとカードの許す限り何枚でも利用可能
    - 魔法触媒が必要触媒の条件を満たしているカードのみ利用可能（触媒は消費しない）
    - カードの効果で敵本体のHPがゼロになったら、その時点でバトル終了で報酬選択へ
    - 使用したカードはゴミ箱に入る。使用回数を使い切ったカードは破棄される（そのバトル中は戻ってこない）
7. カード枚数が最大数を超えていないかチェック
    - 超えていたらカードを選んでゴミ箱に捨てる
8. 味方の攻撃
    - 攻撃対象は「攻撃対象の決定」に従う（敵のクリーチャーがいれば、後から召喚された敵のクリーチャーを攻撃する）
    - 味方の攻撃で敵のHPがゼロになったら敵は消滅する
    - 敵本体のHPがゼロになったら、敵のクリーチャーが残っていてもバトル終了で報酬選択へ
9. 敵のターン開始時効果発動
10. 敵の攻撃
    - 攻撃対象は「攻撃対象の決定」に従う（クリーチャーがいれば、後から召喚されたクリーチャーを攻撃する）
    - 敵の攻撃で味方のHPがゼロになったら味方は消滅する
    - 敵の攻撃で自分（主人公）のHPがゼロになったら、クリーチャーが残っていてもゲームオーバー
11. 味方のターン終了時効果発動
12. 敵のターン終了時効果発動
13. 次のターンへ、3のターン開始時効果発動へ戻る

# バトル終了時の処理
- 主人公のHPのみ、バトル終了後も引き継ぐ
- 次のものはバトル終了時にリセットされる
    - マナ、魔法触媒、アーマー、バトル中の状態効果
    - 召喚したクリーチャー（場から消える）
    - デッキ、ゴミ箱、手札、破棄されたカード（すべてのカードがデッキに戻る。使用回数も元に戻る）
- 「永続」の効果、および装備による基本パラメーターの変化は引き継ぐ

# 敵の行動パターン
各敵は決まった行動パターンを持つ。
基本はループ行動。
一部残りHP等で条件分岐をする場合あり。条件を満たした行動は優先して行う。
敵がクリーチャーを呼ぶ場合もあり。
実行できない行動（敵のクリーチャーが2体いる時の「クリーチャーを呼ぶ」など）は無視し、他の行動を行う。

# 敵の行動予測
次の行動(攻撃○、防御○など)を事前に表示する。先が見えることで考える楽しさを出す
攻撃対象は予告しない。攻撃対象は「攻撃対象の決定」に従い、攻撃の瞬間に決まる。

# 進路選択

## 基本方針
Slay the Spire式の分岐マップを、縦画面向けに小さくした形にする。

- 縦スクロールで下から上へ進む。1ダンジョンは10〜12階（1回の挑戦で通るノードは10〜12個）で、最後はボス
- 各階に2〜3個のノードが並び、次に進める隣接ノードから選ぶ
- 全ノードのアイコンは最初から見えるので、「休憩に寄るために遠回りする」といった計画を立てられる
- 1戦が3〜4分なら、全体で30分前後に収まる

## ノードの種類
- コインとショップは採用しない（ショップノードは存在しない）

| ノード | 内容 | MVP |
|---|---|---|
| 通常戦 | 敵との戦闘。報酬あり | ○ |
| エリート戦 | 強い敵。報酬が良い（装備確定など） | 後から |
| イベント | 選択肢で得失が決まるランダムイベント | ○（数種類） |
| 休憩 | HP回復、またはカード削除、カードランダム交換から1つ選ぶ | ○ |
| 宝箱 | 装備またはレア以上のカード | 後から |
| ボス | 最終階。倒すとクリア | ○ |

## 生成ルール（破綻防止）
- 1階は通常戦のみ
- ボスの直前は必ず休憩
- 中盤に休憩を最低1つ入れる
- エリートは中盤以降にだけ出す
- 分岐の線は交差させない（見た目が分かりやすくなる）

# 報酬選択

## 基本の流れ
バトル勝利後に報酬画面で選択する。通常戦は次の構成とする。

1. カード3択（1枚選ぶ、またはスキップ）
2. 確率で追加報酬（小回復、装備など）

## 戦闘の種類ごとの報酬

| 戦闘 | 報酬 |
|---|---|
| 通常戦 | カード3択＋低確率で装備 |
| エリート戦 | カード3択（レア、レジェンド率アップ）＋装備確定 |
| ボス | カード3択（レア、レジェンドが必ず出る）＋上級装備確定＋ダンジョンクリア |

## カード報酬のルール
- **利用キャラクターで絞る**：使えないカードは出さない（仕様どおり）
- **種別が被らないようにする**：3枚とも攻撃魔法、といった偏りを避ける
- **触媒色の重み付け**
    - デッキ内で多い色のカードが出やすくなる
    - 他の色も最低1枚は混ぜる
    - 色を絞るか広げるかの判断を促す
- **レアリティ**：コモン、アンコモン、レア、レジェンドの4段階。戦闘を重ねるほどレア率が上がる
- **スキップ**
    - デッキは薄いほど強いカードを引きやすいので、正当な選択肢にする
    - 必要なら、スキップで少量HPを回復させる

## 装備報酬
- 指輪、武器、鎧は同種1つしか装備できないため、取るか入れ替えるかの判断が生まれる
- 画面には現在の装備との比較（差分）を表示する
- 入れ替えない場合、装備は破棄して終わりとすると実装が簡単
- マナ基準値、触媒力、ドロー数などの上昇は強力なので、レア以上の装備にしか持たせない
- レア以上の装備はエリート、ボス、宝箱に限定する

## 縦画面での画面構成
- 上部：「勝利」と獲得内容のサマリー
- 中央：3枚のカードを縦または横に並べる（タップで拡大して詳細確認）
- 下部：「スキップ」ボタン（親指が届く位置）

# 画面レイアウト案（追記）

## 共通方針
- スマホ縦画面（9:16〜9:20程度）を基準にする
- 親指が届く下半分に、操作要素（手札、ボタン）を集める
- 画面の上下端はノッチやジェスチャーバーを避けて余白を取る
- 重要ボタン（決定、ターン終了、スキップ）は画面下部に配置し、指で押しやすい大きさにする
- 詳細を見たいもの（カード、敵、装備）はタップで拡大表示する

## タイトル画面
- 上部：ゲームタイトル
- 中央：キャラクターのイラスト
- 下部：「はじめから」「続きから」「設定」（「続きから」は中断データがある場合のみ有効）

## ダンジョン選択画面
- 縦に並べたカード形式のリスト（ダンジョン名、クリア済み表示）
- 未アンロックのダンジョンはロック表示にし、解放条件を表示する
- 下部：「決定」「戻る」

## 主人公選択画面
- 上部：選択中の魔法使いのイラスト（左右スワイプで切り替え）
- 中部：初期パラメーター（HP、マナ基準値、触媒力(赤・青・緑)など）
- 下部：「初期デッキ確認」「決定」「戻る」

## マップ画面
- 上部ヘッダー：HP、現在の階、設定ボタン
- 中央：縦スクロールのマップ（下が開始、上がボス）
    - 現在地にマーカーを表示する
    - 次に進めるノードを強調し、進めないノードは暗く表示する
    - 通過済みのノードは薄く表示する
    - ノードをタップすると種類の説明を表示し、「進む」ボタンで確定する（誤タップ防止）
- 下部固定バー：「デッキ」（確認のみ）、「装備」（指輪・武器・鎧の確認）

## デッキ画面（デッキ確認）
- カードを縦スクロールのグリッド（3列程度）で一覧表示する
- タップでカードを拡大表示する
- 種別、触媒の色、レアリティで表示の並び替え・絞り込みができる（デッキ内の実際の並び順は変わらない）

## バトル画面

| 領域 | 位置の目安 | 表示内容 |
|---|---|---|
| ヘッダー | 上端〜約8% | ダンジョン名、現在の階、設定ボタン |
| 敵エリア | 約8〜38% | 敵本体と敵のクリーチャーを表示（敵本体1体＋敵のクリーチャー最大2体。敵本体は目立つ位置に配置する）。HP、アーマー、状態効果、次の行動予告 |
| 味方エリア | 約38〜56% | 主人公（左）とクリーチャー（右、最大2体）。HP、アーマー、状態効果 |
| ステータス帯 | 約56〜64% | 魔法触媒（赤・青・緑）の現在値と毎ターンの増加分（+1等）、デッキ枚数、ゴミ箱枚数、破棄されたカードの枚数 |
| 手札エリア | 約64〜88% | 手札のカード（最大手札数まで。初期値5枚） |
| 操作帯 | 約88〜100% | マナ（現在値／基準値）、「ターン終了」ボタン |

- **敵の行動予告**：各敵の頭上にアイコンと数値（攻撃12、防御8など）を表示する
- **状態効果**：キャラクターの下にアイコンを表示し、「〇〇ターン」の効果は残りターン数、「バトル中」の効果は専用マークを表示する（「永続」の効果は基本パラメーターに反映されるため表示しない）
- **カードの表示要素**：カード名、種別アイコン、消費マナ、必要触媒（色付きアイコンと数）、レアリティ（枠の色）、効果詳細、使用回数がある場合は残り回数（「残り○回」）
- **カードの使い方**
    - 単体が対象のカード：カードを対象の上までドラッグして離すと使用する
    - 対象を選ばないカード（自分、味方全員、空間など）：カードを上方向へドラッグして離すと使用する
    - 離す前に手札へ戻せばキャンセルできる
    - タップでカードを拡大表示する
- **上限時の召喚**：クリーチャーが2体いる状態で召喚魔法を使うと、入れ替えるクリーチャーを選ぶ表示に切り替わる。クリーチャーをタップして確定し、選ぶ前ならキャンセルできる
- **使用できないカード**：マナが足りないカード、または触媒の条件を満たしていないカードは暗く表示する
- **手札が最大手札数を超えた場合**：捨てるカードを選ぶ画面を表示し、超過枚数を示す
- **デッキとゴミ箱と破棄**：タップで中身を確認できる。デッキは残りカードの内容のみを表示し、並び順は表示しない
- **手札が多い場合**：カードを重ねて表示するか、横スクロールにする

## イベント画面
- 上部：イラスト
- 中央：説明文
- 下部：選択肢ボタン（2〜3個）
- 選択後：結果の文章を表示し、「進む」でマップへ戻る

## 休憩画面
- 上〜中央：休憩のイラスト
- 下部：選択肢ボタン「HP回復」「カード削除」「カードランダム交換」（1つだけ選べる）
- 「カード削除」「カードランダム交換」を選ぶと、デッキ一覧から対象のカードを選ぶ
- カードランダム交換：選んだカードを、同じレアリティのランダムなカードと交換する（利用キャラクターで使えるカードから選ぶ）

## 宝箱画面
- 開封演出のあと、「装備」または「レア以上のカード」を提示する
- 装備の場合は、現在の装備との比較（差分）を表示する
- 「取る」「取らない」を選ぶ

## 報酬画面
- 「報酬選択」の「縦画面での画面構成」を参照

## ゲームオーバー画面・クリア画面
- ゲームオーバー：到達した階、倒した敵の数を表示し、「タイトルへ」ボタンで戻る
- クリア：エンディングのあと、使用した主人公、最終デッキの枚数、アンロックされた要素を表示し、「タイトルへ」ボタンで戻る

# 補足仕様（追記）

## ダンジョンの大きさ（階数）
- ダンジョンごとに「階数」を設定する（例：10階）。最上階はボス
- 各階に2〜3個のノードを置き、1回の挑戦では各階のノードを1つずつ通る（階数＝通るノードの数）
- 戦闘の回数は、選んだ道によって変わる（以前の「全N戦のN」は、この階数に置き換えた）

## ダメージ処理の順序
1. 攻撃のダメージ値を決める（攻撃力最少値〜最大値の間でランダム）
2. 防御力の数値分、ダメージを軽減する（0未満にはならない）
3. アーマーが残っていれば、アーマーから先に減らす
4. 残ったダメージ分だけHPを減らす

## 攻撃対象の決定（自動の攻撃）
- クリーチャーの攻撃・敵の攻撃は、相手側のクリーチャーのうち、後から召喚されたクリーチャーを狙う
- 相手側にクリーチャーがいない場合は、相手の本体（主人公・敵本体）を狙う
- 例：主人公のクリーチャーA、クリーチャーBの順に召喚 → 敵の攻撃はBを狙う。Bが倒れたらA、Aも倒れたら主人公を狙う
- プレイヤーのカード（魔法）はこの制限を受けず、ターゲットを自由に選べる

## イベントの例
- 祭壇：HPを一定量失う代わりに、レアカードを1枚獲得できる（断ることも可能）
- 迷子の精霊：召喚カード（クリーチャー）を1枚獲得できる（立ち去ることも可能）
- 旅の魔法使い：デッキのカード1枚を渡し、同じレアリティ以上のカードと交換する

## ゲーム要素のアンロック
「クリアでゲーム要素アンロック」の対象は次を想定する。

- 新しい主人公
- 新しいダンジョン
- 報酬として出現するカードの種類の追加

## 中断とセーブ
- スマホは中断されやすいため、マップ表示に戻るたびに自動保存する
- 「続きから」で、最後に保存した時点から再開する
- バトル中の中断は、そのバトルの開始時点から再開する

# 決定事項

1. **デッキ調整の内容**：マップ表示中はデッキ確認のみ（デッキ調整は不可）
2. **装備報酬**：「2〜3択で選ばせる」は削除。上級装備はレア以上の装備
3. **効果ターン数のカウント**：効果を受けた側のターン終了時に1減らす
4. **ドロー時に最大手札数を超える場合**：チェックしない。チェックは手番終了時のみ
5. **キャラクター数の上限**：自分側は主人公＋クリーチャー最大2体。敵側は敵本体1体＋敵のクリーチャー最大2体
6. **カードランダム交換の仕様**：同じレアリティのカードと交換する
7. **1ターン目の触媒の増加**：加えない。魔法触媒の初期値はキャラクターごとに異なる
8. **上限時の召喚**：自分側はプレイヤーが指定したクリーチャーと入れ替える。敵側は、敵のクリーチャーが2体いる状態では追加で味方を呼ばず、別の行動を行う
9. **バトルの勝敗**：敵本体を倒したら、敵のクリーチャーが残っていてもバトル終了。主人公が死んだら、クリーチャーが残っていてもゲームオーバー
10. **最大HP**：プレイヤーとクリーチャーに最大HPを追加。回復は最大HPまで。装備などで最大HPを増やせる
11. **ターンの流れのドロー**：マナリセットの後にドローを行う
12. **ターン開始時効果とマナリセットの順番**：現状のまま。マナを増やす効果は「マナ基準値+1」などで調整する
13. **手札の持ち越し**：手札はターンをまたいで残る
14. **アーマーの持続**：アーマーはターンをまたいで残る
15. **バトル終了時のリセット**：主人公のHPのみ引き継ぐ。デッキ、ゴミ箱、手札、破棄されたカードはリセットされ、すべてデッキに戻る
16. **デッキの準備タイミング**：バトル開始時にシャッフル。デッキが空の時にドローが発生したら、ゴミ箱をすべてシャッフルして新しいデッキにする
17. **自動の攻撃の対象**：予告しない。相手側のクリーチャーのうち後から召喚されたクリーチャーを狙い、クリーチャーがいなければ本体を狙う（ターゲット率は廃止）
18. **召喚したクリーチャーの初回攻撃**：召喚したターンの「味方の攻撃」から参加する
19. **カードの使用回数**：1戦闘あたりの使用回数をカード1枚ごとに持つ（0は制限なし）。使い切ったカードは破棄され、そのバトル中は戻らない。次のバトルでは元に戻る
20. **カードのターゲット**：プレイヤーのカード（攻撃魔法を含む）は、相手側にクリーチャーがいても敵本体を自由にターゲットにできる
21. **実行できない敵の行動**：無視して他の行動を行う。条件付きの行動は、条件を満たし実行できる場合は優先する
22. **呼び名**：召喚されて場に出るキャラクター（自分側・敵側とも）を「クリーチャー」と呼ぶ（旧称「仲間」）
23. **ターゲットの追加**：「敵と自分とクリーチャーのいずれか1体」「敵と自分とクリーチャー全員」を追加。単体が対象のほとんどのカードは「いずれか1体」とする
24. **装備の効果**：装備している間だけパラメーターが変わる（外す・入れ替えると元に戻る）。特殊な効果（〜の時に発動など）は今は持たない
25. **ボス報酬**：ルールは用意するが、今はボスに勝つとランが終わるため表示しない（複数のダンジョンを続けて進む仕様などが決まったら表示する）
26. **アンロック**：主人公・ダンジョン・カードに「このダンジョンをクリアすると解放」を設定できる。解放状況は端末に保存する（開発中はタイトル画面のボタンでリセットできる）

# 未確定事項

次の項目は、開発と並行して後で決める（データ・バランス調整）。

1. **状態効果の種類**：バフ・デバフの種類一覧
2. **主人公の初期設定**：主人公ごとの初期デッキと初期パラメーター
3. **各種数値**：レアリティの出現確率、休憩での回復量など
4. **階数**：ダンジョン1つあたりの階数（10〜12程度）
