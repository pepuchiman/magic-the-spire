# ゲーム要素の一覧

Game_Rule.md から切り離した、**ゲームの要素の一覧と、それぞれの細かい動き**をまとめた資料。
状態効果・種族・エフェクト・音は今後も追加していく予定なので、追加・変更する時はこの資料を更新する。
ルールの骨組み（ターンの流れ、ダメージ処理の順序など）は Game_Rule.md を正とする。

# 状態効果

## 共通のルール
- 状態効果は、カードの効果や敵の行動によって、主人公・クリーチャー・敵（敵本体・敵のクリーチャー）に付く
- **バトル中だけのもの**。バトルが終わるとすべて消える（次のバトルには引き継がない）
- 状態効果には、次の2つのタイプがある

| タイプ | 長さの決まり方 | 重ねがけ（同じ状態効果をもう一度受けた時） |
|---|---|---|
| 値が減るタイプ | 毎ターン値が1ずつ減り、0になると消える | 値を足す（効果もターン数も増える） |
| ターン数で続くタイプ | カードの効果ターン数（〇〇ターン／バトル中）の間続く。「〇〇ターン」は、受けた側のターン終了時に1減る | 値とターン数を足す（「バトル中」の効果は値だけを足す） |

- **付いた直後は減らない**：状態効果が付いてから、受けた側がまだ自分のターン（自分側：手番〜味方の攻撃、敵側：敵の攻撃）を迎えていない時は、その直後のターン終了時には減らない（例：敵が主人公に「麻痺1」を与えると、主人公の次のターンに効いてから消える）
  - 受けた側の自分のターン中に付いた効果は、そのターンから数える（例：主人公が自分に「筋力（2ターン）」を使うと、使ったターンと次のターンに効く）
- 状態効果はさらに追加する予定（火傷、再生 など）。追加したら下の一覧に足す

## 一覧

| 名前 | 種類 | タイプ | 効果 | 発動・変化の時期 |
|---|---|---|---|---|
| 毒 | デバフ | 値が減る | 値の分だけHPが減る。防御力・アーマーでは防げない | 受けた側のターン開始時にダメージ → その後、値が1減る |
| 麻痺 | デバフ | 値が減る（値＝残りターン数） | クリーチャー・敵：攻撃しない（防御・クリーチャーを呼ぶ など攻撃以外の行動はする）。主人公：種別が「攻撃魔法」のカードを使えない | 受けた側のターン終了時に値が1減る |
| 弱体 | デバフ | ターン数で続く | 与えるダメージが減る（仮：25%減） | ダメージを与える時 |
| 脆弱 | デバフ | ターン数で続く | 受けるダメージが増える（仮：50%増） | ダメージを受ける時 |
| 筋力 | バフ | ターン数で続く | 与えるダメージが値の分だけ増える | ダメージを与える時 |
| 棘 | バフ | ターン数で続く | 攻撃（攻撃魔法・クリーチャーや敵の攻撃）でダメージを受けた時、攻撃してきた相手に値の分のダメージを返す。返すダメージは相手の防御力・アーマーで減る。毒や棘のダメージには反応しない | ダメージを受けた後 |

- 弱体・脆弱の割合（％）は、ゲーム全体の設定（data/config/game_config.tres）で変えられる
- 筋力・弱体・脆弱・棘がダメージにどう関わるかの順番は、Game_Rule.md「ダメージ処理の順序」を参照

## 敵が状態効果を与える時
- 敵の行動パターンに「状態効果を与える」を入れられる。行動予告に「毒を与える 3」のように表示する
- デバフは、攻撃と同じ決まりで相手を決める（後から召喚されたクリーチャー、いなければ主人公）
- バフは、行動した敵自身に付ける

# 種族

クリーチャー（自分側・敵側）が持つ種族。指定した種族にしか効かない効果がある（例：「自分のクリーチャー」が対象のカードで、種族を限定する）。

| 種族 | 説明 |
|---|---|
| 獣 | 動物の姿をしたクリーチャー |
| 精霊 | 自然の力が形になったクリーチャー |
| 魔獣 | 魔力を持った怪物 |

- 種族はさらに追加する予定。追加したら上の一覧に足す（データの列挙型 GameEnums.Race の末尾にも追加する）

# エフェクト

戦闘中の演出。見た目は data/config/effect_set.tres で種類ごとにシーンを決める（今は ui/effects/ の図形のエフェクト。絵の演出に差し替えられる）。
演出の速さが0の時（テスト）は出さない。

## 攻撃エフェクト（クリーチャー・敵の攻撃）
攻撃した側が相手へ少し踏み込み、攻撃を受けた相手の位置に出る。データの「攻撃エフェクト」で決める。

| 種類 | 見た目 |
|---|---|
| 打撃 | 衝撃の輪が広がる |
| 斬撃 | 斜めの光の線が走る |
| 刺突 | 槍の線が突き刺さり、火花が散る |
| 炎魔法 | 赤橙の粒が揺れながら舞い上がる |
| 水魔法 | 水しぶきの粒 |
| 風魔法 | 渦を巻く線 |

## カードの効果エフェクト
カードが手札から最初の対象へ飛び、着いたら対象全員の位置に出る（対象を選ばないカードは主人公の位置）。データの「効果エフェクト」で決める（「なし」なら飛ぶだけ）。

| 種類 | 見た目 |
|---|---|
| 炎 | 炎魔法と同じ |
| 氷 | 青白い破片が飛び散る |
| 水 | 水魔法と同じ |
| 風 | 風魔法と同じ |
| 雷 | 稲妻が上から落ちる |
| 魔力 | 紫の光の輪が集まって弾ける |
| 毒 | 紫の泡が浮かぶ（毒のダメージの時にも出る） |
| 回復 | 緑の光の粒が上がる |
| アーマー | 青い六角形の盾が光る |
| 強化 | 上向きの矢印 |
| 弱体化 | 下向きの矢印 |
| 召喚 | 足元に魔法陣が広がり、光の柱（クリーチャーが現れる時にも出る） |

## その他の演出
- 状態効果が新しく付いた（値が増えた）時：その状態効果の印がキャラクターの上に浮かんで消える
- 倒れた時：薄くなりながら沈んで消える
- 召喚された時：下から伸びるように現れる
- 大きなダメージ（最大HPの3割以上）：画面が少し揺れる

- エフェクトの種類を増やしたら上の一覧に足す（列挙型 GameEnums.AttackEffect・CardEffect の末尾に追加し、effect_set.tres にシーンを登録する。検証で登録漏れが分かる）

# 効果音・BGM

今は tools/generate_sounds.gd で計算して作った仮の音（assets/sounds/ の WAV）。種類ごとの音は data/config/sound_set.tres で決める。
本物の音にする時は、assets/sounds/ のファイルを同じ名前で差し替える（または sound_set.tres をインスペクターで入れ替える）。
音量は「BGM」と「効果音」で別々に変えられる（設定画面はフェーズ7-4）。バトルの音は、演出の速さが0の時（テスト）は鳴らさない。

## 効果音
| 区分 | 種類 | 鳴る時 |
|---|---|---|
| 攻撃の音 | 攻撃エフェクトと同じ6種類（ファイル名 se_attack_<種類>） | クリーチャー・敵の攻撃 |
| カードの効果の音 | 効果エフェクトと同じ12種類（se_card_<種類>） | カードが対象に着いた時（毒のダメージの時は毒の音） |
| ボタン（se_button） | | ボタンを押した時（全画面） |
| カードを引く（se_card_draw） | | カードを引いた時 |
| カードを使う（se_card_play） | | カードを使った時（飛び始め） |
| ダメージ（se_damage） | | 主人公のカード・棘でダメージを与えた時 |
| 倒れる（se_death） | | クリーチャーが倒れた時 |
| 麻痺（se_paralyzed） | | 麻痺で攻撃できなかった時 |
| ターン開始（se_turn_start） | | 自分のターンの始め |
| 勝利・敗北（se_victory・se_defeat） | | バトルの終わり |
| 報酬（se_reward） | | カードを受け取った時（報酬・宝箱） |
| マップの移動（se_map_step） | | 次のマスへ進んだ時 |
| 装備（se_equip） | | 装備した時 |

## BGM
| 種類 | ファイル | 流れる画面 |
|---|---|---|
| タイトル | bgm_title | タイトル・ダンジョン選択・主人公選択・ランの終わり |
| マップ | bgm_map | マップ・報酬・休憩・イベント・宝箱 |
| バトル | bgm_battle | 通常戦・エリート戦 |
| ボス戦 | bgm_boss | ボスのマスのバトル |

- 曲を変える時は前の曲を小さくしながら切り替え、曲の終わりで最初に戻ってくり返す
- 種類を増やしたら上の一覧に足す（列挙型 GameEnums.SoundEvent・Music の末尾に追加し、音を作って sound_set.tres に登録する。検証で登録漏れが分かる）
